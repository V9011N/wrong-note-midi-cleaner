# MIDIs

Put your data here; its contents are git-ignored (third-party material with its own licences).

One folder per piece:

    <piece>/<name> - PERFECT SOURCE.mid     the written score
    <piece>/<performance>.midi              one or more human performances of that piece
    <piece>/Cleaned/                        written by tools/clean_all.py

Any file not named `PERFECT SOURCE` is treated as a human performance of its folder's piece.
